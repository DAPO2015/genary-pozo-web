# Genary Pozo — web completa para GitHub Pages

## Instalación / actualización

1. Descomprime el ZIP y sube **todos los archivos y carpetas** a la raíz de tu repositorio (no subas el ZIP como un solo archivo).
2. Comprueba que estén `index.html`, las otras cinco páginas HTML, `styles.css`, `app.js`, `sw.js`, `datos-publicos.json` y `assets/`.
3. Mantén en `assets/fonts/` tu copia autorizada de **`Ferron-ExtraExpanded.otf`**. Por licencia, el archivo de fuente no se incluye en esta descarga; si has vaciado el repositorio, súbelo de nuevo desde tu ZIP original.
4. GitHub Pages debe seguir configurado en la rama `main` y la carpeta `/(root)`.
5. Si el navegador conserva la versión anterior, recarga forzosamente o prueba una pestaña privada.

## Ajustes visuales de esta entrega

- El interlineado de los rótulos «GENARY / POZO» es consistente entre portada, pie de página y gráficos de ahorro.
- En móvil se aumenta ligeramente el interlineado para que las líneas no se superpongan.
- El fondo naranja de la fotografía de la chaqueta tiene **exactamente los mismos elementos** que el fondo de «Mi camino»: «TULCÁN · CARCHI», «GENARY / POZO.», «ESCUCHAR · ORGANIZAR · ACTUAR» y círculos decorativos.
- Al activar ahorro solo se ocultan las fotos; los fondos y textos permanecen.
- El archivo de datos públicos no cambia y no se incluye el archivo maestro privado.
