# Genary Pozo · publicación GitHub Pages

## Archivos para reemplazar en el repositorio

Reemplaza estos archivos en la raíz del sitio:

- `index.html`
- `styles.css`
- `app.js`
- `sw.js`
- `datos-publicos.json`

Mantén la carpeta `assets/` con estos archivos:

- `assets/logo-alcalde.webp`
- `assets/genary-hero.webp`
- `assets/genary-cercano.webp`
- `assets/firma-genary.webp`
- `assets/logo-centro-democratico.webp`
- `assets/favicon.png`

## Archivo privado que NO va al repositorio público

- `archivo-maestro.json`

Ese archivo es la fuente de verdad y debe quedarse fuera del repo público.

## Qué cambió en esta versión

- Se eliminó el tono genérico de “archivo público” como eje principal.
- La portada ahora habla directamente de trayectoria, ideas y propuestas.
- Se mejoró el uso de las fotos para evitar recortes incómodos.
- Se añadieron secciones vivas: trayectoria, propuestas, explorador y fuentes.
- `datos-publicos.json` ya contiene la primera versión real derivada del maestro.

## Publicación rápida

1. Sube/reemplaza los archivos indicados.
2. Espera a que GitHub Pages regenere el sitio.
3. Haz un hard refresh del navegador para evitar caché (`Ctrl+F5` o equivalente).
